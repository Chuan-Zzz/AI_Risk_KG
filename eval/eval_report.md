### 2.5 Level 1 分析（仲裁后）

**优势**：
- **高精确率**：整体 Precision 达 97.0%，模型预测的实体绝大多数是正确的
- **高召回率**：仲裁后 Recall 从 70.9% 提升至 92.2%，仲裁消除了标注员间的分歧
- **技术类实体表现优异**：AITechnique (97.5%)、AIModel (96.3%)、AIProvider (98.3%) 的 F1 均超过 96%
- **法规识别精准**：Regulation Precision 100%，Standard 100%

**不足**：
- **Stakeholder 子类型区分仍需改进**：AIDeveloper (77.3%)、AIUser (76.1%) 的 F1 仍低于 80%，大量 Partial Match 说明模型能定位实体但角色分类不准
- **AffectedActor 识别不足**：F1=87.6%，8 个 Incorrect 表明仍有遗漏或误判

**根因分析**：
1. **Stakeholder 角色混淆**：AIDeveloper/AIProvider/AIDeployer 的边界模糊（如 OpenAI 同时是 Developer 和 Provider），导致 `prediction-changed` 比例高
2. **AffectedActor 隐式性**：受影响主体常通过上下文暗示而非显式提及，需要更强的推理能力

## 7. 计算方法说明

### 7.1 Level 1 匹配规则

| origin 字段 | 含义 | 计分 |
|------------|------|------|
| `prediction` | 模型预测，标注员确认 | TP (Exact Match, 权重 1.0) |
| `prediction-changed` | 模型找到实体但标签被修改 | TP (Partial Match, 权重 0.5) |
| `manual` | 标注员手动添加 | FN (模型遗漏) |

**公式**：
- Precision = (TP_exact + 0.5 × TP_partial) / (TP_exact + TP_partial)
- Recall = (TP_exact + 0.5 × TP_partial) / (TP_exact + TP_partial + FN)
- F1 = 2 × P × R / (P + R)

> **注意**：Precision 为上界估计。被标注员删除的错误预测不会出现在标注结果中，因此无法直接统计 FP。如需精确 Precision，需对比 Pipeline 原始输出与标注结果。

### 7.2 Level 2 / Level 3 评分规则

| 评分 | 含义 | 权重 |
|------|------|------|
| 3 ★ | Correct：语义一致，核心含义相同 | 1.0 |
| 2 ★ | Partially correct：方向正确但不够精确 | 0.5 |
| 1 ★ | Incorrect：语义不一致或完全错误 | 0.0 |

**公式**：
- Accuracy = (N_correct + 0.5 × N_partial) / N_total
- Evidence Support Rate = (N_correct + N_partial) / N_total

### 7.3 标注员间一致性 (IAA) 指标计算方法

#### 7.3.1 Inter-Annotator F1（Level 1 实体级）

实体抽取任务无法定义"两人都没标注"的实体（TN=0），Cohen's Kappa 失效，因此采用 NER 领域标准的 Inter-Annotator F1。

对每个共同任务（通过 `event_id` 匹配），提取两位标注员的实体集合 E_A、E_B，匹配条件为 (text, label) 完全相同：

```
TP = |E_A ∩ E_B|       FP_A→B = |E_B - E_A|       FN_A→B = |E_A - E_B|

F1_A→B = 2 × |E_A∩E_B| / (|E_A| + |E_B|)     （以 A 为 gold）
F1_B→A = 2 × |E_A∩E_B| / (|E_A| + |E_B|)     （以 B 为 gold）

Inter-Annotator F1 = (F1_A→B + F1_B→A) / 2
```

解读：<0.5 差，0.5-0.7 一般，0.7-0.8 较好，>0.8 优秀

#### 7.3.2 Gwet's AC2（Level 2 & Level 3 评分级）

评分分布偏斜时 Cohen's Kappa 出现悖论（Po=83.8% 但 Kappa≈0），Gwet's AC2 使用不同的机会一致率模型，不受分布偏斜影响。

```
Po = (1/n) × Σ I(r_A_i = r_B_i)                    观察一致率

π_c = (count_A(c) + count_B(c)) / (2n)              类别 c 的边际概率

Pe^(G) = (2 × Σ_c π_c × (1 - π_c)) / (q - 1)       Gwet 机会一致率
         其中 q 为类别数（本任务 q=3）

AC2 = (Po - Pe^(G)) / (1 - Pe^(G))                  Gwet's AC2
```

解读（Landis & Koch 标准）：<0.00 差，0.00-0.20 轻微，0.21-0.40 一般，0.41-0.60 中等，0.61-0.80 较好，0.81-1.00 优秀
